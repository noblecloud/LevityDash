Weather boards

Four different jobs, same data family. Each one picks a hero and packs context round it, PiConsole-dense. Fonts: Nunito for heroes, Roboto Mono for figures, Roboto for labels (all bundled); the Storm board also tries Barlow Condensed, which would need bundling. Every value maps to a real key or expression, listed under each board. Things the app can't do yet are flagged.

★ Core + rotation

Same density as Everything, with an order to it, and three layered graphs instead of nine: temperature carries feels, dew point and humidity; wind shows speed inside its gust band; rain overlays past and forecast rain, chance and pressure. Temperature, wind and rain are fixed heroes; humidity and pressure are satellites. Sun, sky, moon and soil share one rotating slot (5 s each here). A conditional panel takes the slot over when its condition holds: try Storm. Drawn at 16:10, the shape of a 15in retina screen (2880×1800).

How it maps
  • Fixed panels: the same value-stacks as Everything; heroes get 3 detail columns.
  • The slot is one switch (in progress, not merged): first child whose when: holds shows; children without when: rotate under cycle:. Alerts first, so they beat rotation. 
    - type: switch
  name: sky-slot
  cycle: 15s
  hold: 30s
  fade: 400ms
  items:
    - {type: group, name: lightning, when: 'environment.lightning.distance < 10 and environment.lightning.last < 30m', ...}
    - {type: group, name: freeze, when: 'environment.temperature.temperature < 34', ...}
    - {type: group, name: sun-uv, ...}
    - {type: group, name: sky, ...}
    - {type: group, name: moon, ...}
    - {type: group, name: soil, ...}
  • The Rain hero is a switch too: when: environment.precipitation.precipitation > 0.3 shows the storm state, else the normal one.
  • Other conditionals worth having: Freeze (temp < 34°F: frost time, soil temp), Heat (heat index > 95), Wind advisory (gust > 40). Each would take the same slot.

0 · Everything

Answer to "still super data sparse": ten panels, ~110 readings, plus the next 12 hours and the next 7 days. Each panel has a hero, a 2-column detail grid, a 24h spark as its base layer and a plain-words state. Value-stacks in a stack of groups; in .levity this is mostly bare keys.

Keys

All from the key list (OpenMeteo, PirateWeather, WeatherFlow). Low/high = min/max(k,24h), Δ = k - at(k,-1h) or -3h. "at 05:12" times and the plain-words lines need arg-min/max and a text-mapping function new; without them those cells drop, the rest builds today. Lightning, soil and VPD need WeatherFlow/OpenMeteo extras switched on.
